# 人工编写的教学说明

[English](expected-findings.md) | [简体中文](expected-findings.zh-CN.md)

以下是为合成示例编写的预期问题，不是 AI 回复，也不能证明某个模型实际发现了这些问题。

1. **写入后、更新进度前崩溃：** 数据已保存在 `store` 中，但 ID 尚未进入 `state["done"]`。重试会再次写入。正常流程测试没有覆盖这个时间窗口。
2. **同一批次内 ID 重复：** `state["done"]` 在循环结束后才更新，因此同一批次里两个此前未见过的相同 ID 都会被写入。
3. **内存集合不能完整解决崩溃问题：** 在循环中更新临时集合能处理批内重复，却不能让两个独立的持久化存储具有原子性。要满足崩溃重试要求，需要存储层唯一 ID、幂等写入，或适当的事务。

有用的审阅应解释具体失败顺序并建议针对性测试，不应声称自己运行过代码或访问过真实数据库。
